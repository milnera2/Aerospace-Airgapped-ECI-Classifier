# aerospace-airgapped-eci-classifier
A secure, locally hosted multi-agent AI system designed to assist Export Control Officers in classifying aerospace components. By executing strictly on-premises using Ollama and Chainlit, this workflow eliminates the federal compliance violations associated with cloud APIs. The system utilizes a specialized, three-agent architecture (Technical Extractor, Legal Cross-Referencer, and Compliance Marking Generator) to evaluate mechanical specifications against ITAR and EAR frameworks, ensuring high accuracy while actively preventing automation bias and false negatives through hard-coded human intervention triggers.
